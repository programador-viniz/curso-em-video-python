# Curso em Vídeo Python 🐍

Repositório pessoal de estudos com os exercícios do curso Python 3, ministrado por Gustavo Guanabara, do Curso em Vídeo.

## Objetivos 🎯

- Praticar os fundamentos da linguagem Python.
- Resolver os exercícios de cada mundo do curso.
- Aprender a utilizar Git para controle de versão.
- Gerenciar o ambiente de desenvolvimento com uv.
- Manter o código organizado com Ruff.

## Tecnologias 🤖

- Python
- Git
- Visual Studio Code
- uv
- Ruff

## Organização 📁

- `mundo-1/`: exercícios introdutórios.
- `mundo-2/`: exercícios de estruturas condicionais e de repetição.
- `mundo-3/`: exercícios de estruturas de dados e demais conteúdos do curso.

## Como executar 💿

É necessário ter Git, uv e VS Code instalados.

Para executar um exercício, utilize o terminal na raiz do projeto:

```powershell
uv run python mundo-1/ex001.py
```

Para verificar o código com Ruff:

```powershell
uv run ruff check .
uv run ruff format --check .
```
